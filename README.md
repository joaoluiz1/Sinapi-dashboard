# SINAPI Dashboard Pro 🏗️

Ferramenta interativa para análise de composições e insumos do SINAPI (2026).

## 🚀 Como Executar
1. Instale o Python.
2. Instale as dependências: `pip install -r requirements.txt`.
3. Execute o comando: `streamlit run app.py`.

## 🛠️ Tecnologias
- Python 3.x
- Streamlit
- Pandas
